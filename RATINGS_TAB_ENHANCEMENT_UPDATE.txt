================================================================================
                          DATA CALCULATIONS
================================================================================

SATISFACTION AVERAGE:
  satisfactionAvg = Σ(satisfaction_rating) / total_ratings
  Example: (5 + 4 + 5 + 3) / 4 = 4.25

COMPLETENESS AVERAGE:
  completenessAvg = Σ(completeness_rating) / total_ratings
  Example: (4 + 3 + 4 + 3) / 4 = 3.50

ENGAGEMENT AVERAGE:
  engagementAvg = Σ(engagement_rating) / total_ratings
  Example: (5 + 4 + 5 + 4) / 4 = 4.50

OVERALL AVERAGE:
  overallAvg = (satisfactionAvg + completenessAvg + engagementAvg) / 3
  Example: (4.25 + 3.50 + 4.50) / 3 = 4.08

SATISFACTION RATE:
  (ratings with satisfaction >= 4) / total_ratings * 100
  Example: 3 / 4 * 100 = 75%
